## 8.1. Tools
---
Project-Polearm uses the open source Godot game engine along with the programming languages GDScript and C#, which specifically requires the .NET build of Godot. The project started development in Godot version 4.6, and the final version uses Godot 4.7. The game relies on the external physics engine _Jolt_ built into Godot. The only external runtime dependency is the PhantomCamera plugin for Godot, which is included in the source code distribution.

VSCode was used as an external IDE with Git for version control, with the repository being hosted on GitHub. Blender was used as a 3D modelling software used to create 3D assets, alongside Aseprite, Krita and Sketchbook for 2D assets such as textures or UI elements.

## 8.2. Running Project-Polearm
---
The provided source code contains all assets necessary to run and build the game. To run Project-Polearm in engine from source, one needs to download the Mono build of Godot on version 4.7. Pressing the run project button will boot the game as expected in executable builds. The game has been tested and is proven to work definitely on following platforms with these input methods:

|                  | **Windows 11**                    | **Linux (Distribution: Arch)** | **macOS Tahoe**                                |
| ---------------- | --------------------------------- | ------------------------------ | ---------------------------------------------- |
| **x86 (64 bit)** | In-Engine & Executable (Keyboard) | In-Engine (Keyboard)           | Not tested                                     |
| **ARM64**        | Not tested                        | Not tested                     | In-Engine & Executable (Keyboard & Controller) |
