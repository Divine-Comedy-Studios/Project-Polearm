# AI usage: LevelMesh

`LevelMesh.gd` (October 2026) was at least partially generated by the use of generative AI.

It was generated with Claude or ChatGPT, each in the free version that was available at the time.

**The original prompts were not saved.** The prompts below are reconstructions: they are prompts that could have produced this code and describe what we asked for, but we did not necessarily use the same wording. The generated code was changed and adapted by us afterwards.

Reconstructed prompts (in order):

1. write a godot tool script for a node that i put above my imported blender level. it should apply one shared stylized shader material to all meshes below it and keep their original colours and textures
2. add a checkbox in the inspector that generates trimesh collision (static bodies on the world layer) for every mesh below the node, and one that removes it again. nothing should be created automatically
